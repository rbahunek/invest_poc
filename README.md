# invest_poc

Pokretanje `python sp500_portfolio_poc.py` izrađuje sažetak pokazatelja za 100
dionica (`output/sp500_portfolio.csv`) i zaseban dugi niz neprilagođenih dnevnih
`Close` cijena (`output/yahoo_close_prices.csv`). Detalji izvora, formula,
rezervnog postupka i kontrola opisani su u [METODOLOGIJA.md](METODOLOGIJA.md).
